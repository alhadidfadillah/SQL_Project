# Baby Names Trend Analysis
## About Data
Baby names from social security card applications in the United States spanning three decades, including state, gender, year of birth, name, and the number of babies given each name.
## The Goals
View trends in baby name popularity based on US Social Security data from 1980-2010.
## The Objectives
1. Track Changes in Popularity: See how the most popular names have changed over time, and also identify the names that have jumped the most in terms of popularity.
2. Compare Popularity Across Decades: Find the top 3 girl names and top 3 boy names for each year, and also for each decade.
3. Compare Popularity Across Regions: Find the number of babies born in each region, and also return the top 3 girl names and top 3 boy names within each region.
4. Explore Unique Names: Find the most popular androgynous names, the shortest and longest names, and the state with the highest percent of babies named "Chris".
